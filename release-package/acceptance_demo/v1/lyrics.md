# 盛夏的约号

> 结构：Verse-Chorus-Verse-Bridge-Chorus-Outro | 版本：v1

## [主歌 1] (温暖克制)
课桌上刻下的痕迹还在发烫
走廊的风吹翻泛黄的时光
整理好的行囊靠在门旁
我们笑着说今天谁也不许哭花了妆

## [副歌] (不舍与约定)
奔向人海吧 别回头看夕阳
各自的远方都有漫天星光
等下一个夏天 无论身在何方
只要那首熟悉的旋律再次奏响 终会再遇上

## [主歌 2] (怀念)
最后一次关掉自习室的灯光
单车后座哼过的歌还在回响
相片里的少年眼神格外清亮
把所有青涩的梦悄悄折进行李箱

## [过渡段] (释怀与坚定)
车站的汽笛声催促着启程的行囊
挥动的手臂定格成青春的倔强

## [副歌] (爆发与感动)
奔向人海吧 别回头看夕阳
各自的远方都有漫天星光
等下一个夏天 无论身在何方
哪怕岁月漫长 我们一定会在顶峰相望

## [尾声] (克制温情)
再见啦 朋友
再见啦 我们的盛夏时光
